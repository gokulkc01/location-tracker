# 📍 Location Tracker

A modern, real-time location tracking application built with the MERN stack for keeping your loved ones safe.

![Location Tracker](https://img.shields.io/badge/MERN-Stack-green)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- 🔐 Secure Authentication (JWT)
- 👥 Circle-based Location Sharing
- 📍 Real-time Location Tracking
- 🗺️ Interactive Maps with Leaflet.js
- 🆘 Emergency SOS Alerts
- 🔋 Low Battery Warnings
- ⚡ Real-time Notifications (Socket.io)
- 📊 Activity Logging
- 🎨 Beautiful Modern UI

## 🏗️ Tech Stack

**Frontend:**
- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Leaflet.js
- Socket.io-client

**Backend:**
- Node.js
- Express.js
- MongoDB
- Socket.io
- JWT

## 🚀 Quick Start

### Prerequisites
- Node.js v18+
- MongoDB
- npm or yarn

### Backend Setup

\`\`\`bash
cd location-tracker-backend
npm install
cp .env.example .env
# Edit .env with your configuration
npm run dev
\`\`\`

### Frontend Setup

\`\`\`bash
cd location-tracker-frontend
npm install
cp .env.example .env
# Edit .env with your API URLs
npm run dev
\`\`\`
